# Gestor de Proyectos

Aplicación web para asignar proyectos a equipos, dividirlos en fases y hacer seguimiento del avance en tiempo real, con recordatorios automáticos por correo.

**Stack:** React + Vite + Tailwind + shadcn/ui · Supabase · Python (worker) · GitHub Actions · Vercel
